## 四、发现的问题

1. **模板线框图图例色块显示成细线**：`.swatch` 是 `<i>` 行内元素，只有宽高不生效。已修：`.swatch{display:inline-block;...}`。
2. **中文粗体紧贴全角标点时不生效**：`**……（6）。**两半` 在 marked 里不会被识别为 `strong`（换成 `**……（6）。** 两半` 正常）。不是插件的 bug，但 AI 生成 HTML 时要注意在 `**` 后留空格或换行。
3. **HTML 阅读版没有内置编译器**：D5 / D7 仍由 AI 手写 HTML；测试用了临时脚本（未入库）。
4. **旧项目迁移**：`需求调研.md` 仍可被识别为调研分析的 md；铺板快算已生成 `docs/调研分析.md` 并把 `artifacts.demand` 指过去，同时补了 `调研分析.html` / `PRD.html` / `CLAUDE.html`。
